# 로컬 대상 구조

IWANTGOHOME은 특정 제품에 종속되지 않는 대상 모듈 구조를 사용합니다.

대상 모듈은 범용 분석 엔진에 연결되어 다음 과정을 구현할 수 있습니다.

    소스 준비
    → 실행 환경 준비
    → 검증용 데이터 구성
    → 후보 검증
    → 전체 분석
    → 상태 확인
    → 종료 또는 초기화

각 대상 모듈은 필요에 따라 다음 기능을 제공합니다.

- 소스와 버전 확인
- 격리된 실행 환경 준비
- 검증용 사용자와 자원 생성
- 정상 동작 구성
- 의심 동작 구성
- 버전별 재검증
- 결과와 근거 저장

공개 코어에는 특정 제품용 대상 모듈을 기본 포함하지 않습니다.

새로운 대상은 공통 인터페이스를 구현하여 연결할 수 있습니다.
